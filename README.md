# humopage

Marketing website for **Humo Racing** — a Formula Student team from Tashkent.

## Stack

- React 18 + Vite 5
- Tailwind CSS 3.4

## Development

```bash
npm install
npm run dev       # local dev server
npm run build     # production build to dist/
npm run preview   # preview the production build
```

## Deploy

The `dist/` folder is served by the production Express server in the
`humo-racing` deployment.
